# Copy-Markdown-Link-Bookmarklet
This is a simple bookmarklet made by me for the [Hacklet](https://hacklet.hackclub.com/individuals.html) program! It basically copys the link for markdown such that it functions like a hyperlink. For Eg- 

```[Page Title](https://example.com/page)```

By the way, I copied the Hacklet hyperlink with this bookmarklet only!
